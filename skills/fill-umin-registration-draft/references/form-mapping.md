# フォーム対応と注意点

## 操作境界

UMIN公式マニュアルで、フォーム単位の保存と正式登録は別手順とされている。画面は変更され得るため、現在の見出しと案内文で確認する。

| 現在の画面・操作 | このワークフローでの扱い |
| --- | --- |
| 個別フォームの「確認画面へ」 | 当該フォームの内容確認に使う |
| 当該フォームの確認画面の「登録」 | フォーム単位の保存だと確認できた場合だけ押す |
| 基本情報保存後の「先に進む」 | 受付番号を伴う下書き入力の継続だと確認して使う |
| 保存後の「フォームの選択」 | ほかの入力フォームへ戻るために使う |
| フォーム選択画面の「入力内容確認」 | 押さない。ここで止める |
| 「データの最終確認」「登録処理」の画面 | 遷移しない。偶然到達したら操作を止める |
| UMIN試験IDを発行する正式な「登録」「送信」等 | 実行しない |

Rで始まる受付番号は正式なUMIN試験IDではない。公開希望日を将来に設定してあっても、正式登録はこのスキルの範囲外とする。同名ボタンを根拠に自動で続行しない。

## 対応表

入力名・言語・選択肢コードは [form-catalog.json](form-catalog.json)、反復操作は [操作コードの使い方](browser-automation.md) を参照する。必要なフォームだけ読む。対応表に実際の入力値を保存しない。

| フォーム | Wordの情報 | 照合点 |
| --- | --- | --- |
| 基本情報 | 一般向け／科学的試験名、各略称、地域 | 日本語と英語の4組を取り違えず、独自に改題しない |
| 目的 | 疾患、区分、ゲノム、目的、性質、フェーズ、主要／副次アウトカム | 目的2の注記と主要評価項目を区別し、未選択を推測で埋めない |
| 試験デザイン | 割付、盲検、対照、群数、介入、適格性、人数 | 年齢の以上／超／以下／未満を日本語で確認する。選択・除外基準の番号を日英で照合する |
| 管理情報等 | 責任研究者、問い合わせ、送信者、スポンサー、資金、IRB、他ID、施設、公開日 | 姓名の欄順、公開／非公開IRB、専用の郵便番号欄を確認する |
| 結果等 | 公開状況、結果、参加人数、IPD等 | 結果を創作せず、目標人数を実組入れ人数へ流用しない |
| 進捗等 | 状況、プロトコル、IRB承認、開始・終了等の日付 | 公開日・組入れ日・プロトコル確定日を混同せず、空欄を残す |

## 機関選択と英語欄

- スポンサーと研究費提供組織を別項目として扱う。同じ機関でも役割をまとめない。
- 機関選択で原稿の機関を検索する。0件なら画面の案内に従い「その他」を選んで直接記入する。類似組織を代用しない。
- ポップアップは開いた後のタブ一覧で特定し、固定タブIDを使わない。
- 半角制限には最小限の文字置換で対応する。日本語にしかない菌数や用量を勝手に翻訳追加せず、差異を報告する。
- 今回の原稿とユーザー修正を使い、過去の別試験の連絡先を使い回さない。

## 保存前の確認

1. 試験／受付番号、フォーム、言語が一致しているか。
2. 番号・改行・選択記号が保たれているか。
3. 人数、期間、用量、単位、不等号、日付が一致しているか。
4. 変更履歴の旧文、注記、空の選択肢が混入していないか。
5. 未選択・未記入と、明示された「なし」を区別しているか。
6. 保存対象がフォーム単位であり、最終確認・正式登録ではないか。
