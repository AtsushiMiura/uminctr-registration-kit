# uminctr-registration-kit

UMIN登録用のWord原稿を、UMIN-CTRの各フォームへ転記・照合・保存するChrome拡張とCodexスキルです。項目の対応表を共用し、文字制限、日英の欄、番号・改行を確認します。最終確認画面への遷移、正式登録・公開は行いません。

## Chrome拡張

定型DOCXをMammothで端末内解析し、判断できない項目を利用者が確定してから一括入力します。外部AIや外部の変換サービスは使いません。練習用と本番の登録前下書き用を別ビルドにし、新規基本情報作成と、基本情報入力済みの下書きへの続きの入力に対応します。登録済み試験の更新には対応しません。

架空原稿で両環境の全6フォームの保存・照合と、最終確認手前での停止を実機確認しています。本番ではBusyによる停止後、再開して完了しました。導入手順、停止後の再開方法、検証範囲は[拡張のREADME](extension/README.md)、読み取り規則は[書式対応と判断基準](extension/FORMAT_SUPPORT.md)を参照してください。社内の一括配布・更新方式は未確定です。

## Codexスキル

[`$fill-umin-registration-draft`](skills/fill-umin-registration-draft/SKILL.md) の明示指定で起動します。最終確認画面への遷移、正式登録・公開は行いません。

Codexにスキルを配置したうえで、ブラウザで対象のUMINフォームを開き、Word原稿のパスと対象画面を指定します。

```text
$fill-umin-registration-draft
「/path/to/UMIN登録案.docx」を、Chromeで開いている対象試験のフォームへ入力してください。
各フォームを保存し、フォーム選択画面で止めてください。
```

部分修正では、対象項目と変更内容も指定してください。練習画面で試す場合は「ダミー入力でテスト」と明記します。原稿や入力済みデータはリポジトリに保存しないでください。
